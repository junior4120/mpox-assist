# Meta-Learning — Phase 3 (recherche)

Ce dossier est réservé à l'exploration scientifique du méta-apprentissage
(ex. Prototypical Networks, Few-Shot Learning) pour le contexte de
faible disponibilité de données Mpox.

**Aucune implémentation n'est présente ici tant que la Phase 1 (MVP)
et la Phase 2 ne sont pas stabilisées**, conformément au principe :
« le MVP doit fonctionner avant de passer aux phases 2 et 3 ».

## Objectif futur

Comparer expérimentalement :

- Transfer Learning (MobileNetV3 / EfficientNet pré-entraînés, fine-tunés)
- Meta-Learning (Prototypical Networks ou équivalent)

sur la tâche de classification Mpox / Varicelle / Herpès / Peau saine,
avec peu d'exemples par classe.

**Aucune affirmation de performance ne sera faite avant mesure
expérimentale réelle et documentée.**
